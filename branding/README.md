# ScrapSheet branding

## App icon

`app-icon.png` (1254 × 1254) is **the** ScrapSheet app icon: a teal spiral
notepad with two text lines on a mint page, on a cream rounded square.

Use it everywhere the app is installed or listed:

- Web app home-screen / taskbar icons (iOS "Add to Home Screen", Windows/Chrome/
  Edge installs, the web manifest, favicons)
- The Android app (launcher and adaptive icon, Play Store listing)
- The iOS app (App Store icon set)

Platform sizes are made from this file. It isn't wired into `public/` yet: the
full branding kit is coming, and the installed-app icons will be regenerated
from it then.
